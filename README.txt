# The Office Mystery

This version changes the previous multi-room game into one interactive hidden-object office scene.

## Files

- index.html
- style.css
- script.js
- assets/images/mystery_room_office_shelves.png  <-- your existing office image

## Required image

The JavaScript expects this exact path:

assets/images/mystery_room_office_shelves.png

Keep your existing office image at that location.

## Optional music

This version uses browser-generated sound effects, so it does NOT require an MP3 file.

## Game behavior

- One office scene only
- No Room 1 → Room 2 navigation
- No visible clue numbers
- 8 hidden challenge objects
- Decorative objects can also be clicked
- Correct answer = +10 points
- Wrong answer = -2 points, minimum score 0
- 20-minute timer
- Team Alpha / Team Bravo question sets
- 8/8 clues unlock the Master Key
- Victory and time-up screens
